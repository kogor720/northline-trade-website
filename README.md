# 基础外贸网站

双击 `index.html` 即可查看，无需安装依赖或构建。

支持 English、简体中文和繁體中文，默认英文，右上角可切换并记住选择。包含产品分类筛选、公司介绍、采购流程、询盘表单和移动端导航。品牌及产品均为演示资料，不包含虚构资质或交易数据。

询盘按钮打开本机邮件客户端，不会自动发送邮件，也未连接服务器。正式使用前请将 `index.html` 和 `script.js` 中的 `sales@example.com` 替换为真实邮箱，并替换公司、产品信息。若需要在线收集询盘，可后续接入表单服务或后端。

主视觉照片来自 Unsplash，字体来自 Google Fonts，联网时加载；产品插画内置，页面无需联网也能显示基础内容。

文件可直接部署到任意静态网站托管服务。
